# Cabin Sketch

Author: The Cabin Project Authors / Pablo Impallari.

The font has a drawn, irregular stroke built into its glyphs. Its regular cut
complements the existing bold Cabin Sketch file from the shared media library.
The font files are unmodified; no installed system font is required.
